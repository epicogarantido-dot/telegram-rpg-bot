# OpenStax — Introduction to Business (1ª ed., CC BY 4.0)

Cursos traduzidos e adaptados na sessão (sem API paga), a partir das seções do livro.

- `baixar.py` / `baixar2.py`: baixam o texto das seções pela API pública do archive da OpenStax (`sec-*.txt`, fora do git).
- `cursoN.py <saída.json>`: geram o JSON de cada curso em `data/cursos/` (o JSON é a fonte da verdade; os scripts ficam pra referência).
