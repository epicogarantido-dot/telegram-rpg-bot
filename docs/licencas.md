# Licenças e fontes

**Grátis não é o mesmo que aberto.** Um curso gratuito no Coursera, na Udemy ou no
YouTube continua protegido por direito autoral: traduzir e republicar é infração,
e é o tipo de coisa que derruba um site inteiro (notificação DMCA, remoção do
domínio, processo). Este projeto só republica material com licença aberta que
permita **obra derivada** (tradução é obra derivada).

| Licença | Pode traduzir? | Condições |
|---|---|---|
| CC0, MIT, BSD | Sim | Manter aviso de copyright (MIT/BSD). |
| CC BY | Sim | Crédito ao autor + link da licença. |
| CC BY-SA | Sim | Crédito + a tradução sai sob a mesma licença. |
| CC BY-NC(-SA) | Sim | Crédito, **sem uso comercial** (nada de anúncio/cobrança nessas páginas), (-SA) mesma licença. |
| CC BY-ND, "todos os direitos reservados" | **Não** | Só dá pra linkar o original. |
